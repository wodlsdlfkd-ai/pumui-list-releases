# 품의목록 생성기 배포

이 저장소는 Windows용 품의목록 생성기 설치 파일과 자동 업데이트 정보를 배포하는 곳입니다.

## 설치 및 업데이트

1. [Releases](https://github.com/wodlsdlfkd-ai/pumui-list-releases/releases)에서 최신 정식 설치 파일을 내려받습니다.
2. 실행 중인 앱을 닫고 설치합니다. 기존 사용자는 앱에서 품의를 백업한 뒤 같은 경로에 설치합니다.
3. 자동 업데이트 기능이 포함된 첫 버전을 한 번 설치한 다음부터는 앱 왼쪽 아래 ‘업데이트 확인’에서 새 버전을 받을 수 있습니다.
4. ‘업데이트 받기’ 후 ‘저장 후 재시작하여 업데이트’를 누르면 저장과 백업을 마친 뒤 앱이 업데이트됩니다. ‘나중에’를 선택하면 현재 버전을 계속 사용합니다.

선생님은 GitHub 계정이나 GitHub 토큰을 입력할 필요가 없습니다. 품의 목록·원본 이미지·개인 API 키는 업데이트 서버로 보내지 않습니다. 학교에서 GitHub 다운로드를 차단하면 수동 설치 파일을 사용해야 할 수 있습니다.

## 제작자 배포 메모

한 버전의 설치 EXE, EXE.blockmap, latest.yml은 빌드가 생성한 묶음 그대로 함께 게시합니다. 앱은 정식 릴리스만 확인합니다. 최신 버전 번호가 더 높은 릴리스로 배포하고 이미 게시한 같은 버전의 파일을 바꾸지 않습니다.

이 문서와 공개 릴리스 설명에는 사용자 품의 자료나 인증 정보를 넣지 않습니다.
